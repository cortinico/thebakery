Running with Enrique López-Mañas

In this special episode we ask Enrique to tell us his personal experiences with Running

Enrique López-Mañas · 2 Oct 2021 · 01:00:13
Also on Spotify Apple Podcasts Pocket Casts RSS

So we made it to Episode 20! 🎂.

If you’ve been enjoying this podcast so far, please consider making a small donation to my London Marathon 2021 fundaraising. You’ll be supporting Mencap, the voice of Learning Disabilities 🙏 Thank you so much.

We’re celebrating this milestone with a special episode. The tool we’re going to talk about today is not a Github library, but a sport that is getting more and more popular in the developer community: Running 🏃‍♂️.

I’m excited to have on stage Enrique López-Mañas, GDE for Kotlin & Android, Maitnainer of Kotlin Weekly and (Ultra) Marathon runner.

Enrique will share with us his passion for running and will tell us how software engineers can benefit from this sport. He has also been successufully running Kotlin weekly for the last 5 years, so he has a lot to tell about endurance as well.

Enjoy the show 👨‍🍳
